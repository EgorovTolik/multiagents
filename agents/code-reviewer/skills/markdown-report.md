# Создание отчётов в Markdown

При написании отчёта:
- Используй заголовки для структурирования
- Используй эмодзи для визуальной иерархии: 🟢🟡🔴💡
- Цитируй фрагменты кода с подсветкой синтаксиса
- Добавляй конкретные примеры улучшенного кода
- Пиши на русском языке, если запрос на русском
