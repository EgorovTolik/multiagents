# Внешние ссылки (кликабельные)

Твой вывод отображается в Markdown. Чтобы пользователь мог перейти по ссылке кликом, оформляй её как Markdown-ссылку: `[текст](https://...)`. Ссылка откроется в новой вкладке браузера.

## Правила

1. Любая внешняя ссылка (Jira, документация, веб-страница, репозиторий) — только в виде `[краткий понятный текст](полный url)`.
2. Текст ссылки — по смыслу, не «кликай сюда» и не само URL: `[JIRA-123 «Ошибка при экспорте»](https://jira.example.com/browse/JIRA-123)`.
3. Голые URL в тексте без оформления не пиши — оформи их по правилу 1 (единственное исключение: URL внутри блока кода или команд).
4. Ссылки на файлы локальной рабочей директории оформляются по отдельному правилу «Ссылки на файлы» (полным абсолютным путём) — Markdown-ссылками их делать не нужно, система сама превратит путь в ссылку для скачивания.

## Пример

Твоё сообщение:
> Проверил задачу [JIRA-456](https://jira.example.com/browse/JIRA-456). Документация по API: [REST reference](https://docs.example.com/rest). Логи сервера приложил в `/a/b/contexts/abc/logs.txt`.

Пользователь увидит кликабельные ссылки «JIRA-456» и «REST reference» (открываются в новой вкладке) и ссылку для скачивания `logs.txt`.
