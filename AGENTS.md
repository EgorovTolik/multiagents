# Запуск сервера multiagents

## Скрипт run.sh

В корне проекта создан скрипт `run.sh` для запуска сервера с автоматической синхронизацией компонентов.

**Почему это нужно:** Инструменты планирования импортируют `@multiagents/plan-manager` из `server/node_modules`. Если в компоненте были изменения — их нужно "обновить" в node_modules, иначе сервер будет использовать устаревшую версию. Скрипт делает это автоматически через `npm link`.

## Как запустить

```bash
# Дать права на выполнение (один раз)
chmod +x run.sh

# Запуск сервера
./run.sh
```

Сервер доступен по адресу `http://localhost:3000`

## Что делает скрипт

1. Синхронизирует компонент plan-manager в node_modules через `npm link`
2. Останавливает все существующие процессы сервера
3. Запускает новый сервер через `nohup` (не остановится при закрытии терминала)
4. Выводит PID процесса и пишет логи в файл `server.log`

Логи сервера пишутся в файл `server.log` в корне проекта.

Для перезапуска просто выполните `./run.sh` снова — скрипт сам остановит старый процесс и запустит новый.

## Правила работы агентов

- **Не делайте коммиты самостоятельно.** Всегда спрашивайте у пользователя разрешения перед сохранением изменений в git. Коммит выполняется только когда пользователь явно попросит об этом.
- **run.sh запускать в блокирующем режиме** (без `&`, без таймаутов). Скрипт сам проверяет что сервер запустился и сообщает об успехе — не нужно дополнительно проверять через lsof или curl.
