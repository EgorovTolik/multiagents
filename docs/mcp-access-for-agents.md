# Доступ агентов к MCP

## Где настраивается MCP

MCP-серверы конфигурируются один раз на уровне pi (глобально), а не на проект или отдельного агента:

- **`~/.pi/agent/mcp.json`** — список MCP-серверов (command, args, env).
  Каждый сервер задаётся отдельно: `chrome-devtools`, `jira`, `oracle-vc-dev` и т.д.
- **Адаптер `pi-mcp-adapter`** — глобальный пакет pi (`~/.pi/agent/settings.json → packages`).
  Он подключает MCP-серверы к каждой pi-сессии и регистрирует в ней:
  - прямые инструменты по каждому инструменту каждого сервера (с префиксом сервера);
  - гейтвей **`mcp`** — единая точка доступа ко всем серверам: статус, поиск инструментов,
    описание параметров, вызов, OAuth;
  - **`mcpScript`** — JS-скрипты с несколькими MCP-вызовами в одном запросе (циклы, ветвления).

Сессии multiagents создаются с тем же `agentDir = getAgentDir()` (~/.pi/agent),
поэтому адаптер загружается в них автоматически. Раннер дополнительно вызывает
`session.bindExtensions({})` при создании сессии — это отправляет событие
`session_start`, необходимое для инициализации MCP-подключений.

## Allowlist инструментов агента

Каждый агент работает только с инструментами из своего allowlist:

```
allowlist = (tools из agents/<id>/config.json)
          + системные инструменты (route_to_agent, list_agents, ask_user, handoff_file)
```

Если в `config.json` агента нет поля `tools`, используется дефолтный набор
`read`, `bash`, `edit`, `write`. Инструменты вне allowlist (включая MCP-инструменты)
pi не регистрирует для сессии — агент их физически не видит.

Следовательно, чтобы агенту были доступны MCP:

- в его `agents/<id>/config.json → tools` должны быть **`mcp`** и/или **`mcpScript`**.
  Через гейтвей `mcp` доступны все серверы из `~/.pi/agent/mcp.json`;
- прямые инструменты конкретных серверов — если их имена также включены в allowlist.

## Настройки по умолчанию

При создании нового агента (`create_agent` / редактор) в `tools` автоматически
включаются `mcp` + `mcpScript`. Отключить можно в редакторе агентов
(чекбоксы `mcp` / `mcpScript`). У старых агентов без поля `tools` MCP недоступен,
пока чекбоксы не будут отмечены вручную.

## Как проверить доступ у агента

1. Посмотреть `agents/<id>/config.json` → поле `tools` содержит `mcp` или `mcpScript`;
2. либо спросить агента в чате: «какие инструменты тебе доступны».
