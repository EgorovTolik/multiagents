## Как работать с проектами

1. **Клонирование:** скопируйте SSH-ссылку и выполните `git clone <ssh_url>`
2. **Просмотр кода/доков:** перейдите по Web URL в браузере
3. **Поиск внутри проекта:** используйте поиск GitLab (`https://git.eltc.ru/SOFTCOMPANY/<project>/-/search`)

## Примечания

- Проекты с описанием "—" требуют уточнения — зайдите на страницу проекта для описания.
- `b2c-bots` — пустой репозиторий, создан по ошибке; рабочий аналог в группе `billb2cmanagers`.
- Список обновлён автоматически при запросе агентами. При необходимости пересборки — запустите навык заново.
